Click "Attempt Login" to trigger the cross-origin request. Then observe the red CORS error logged in DevTools Console.
Why does this error occur?
Under the browser's Same-Origin Policy (SOP), an origin consists of protocol + domain + port. Because the frontend (port 3000) and API (port 5000) have different port numbers, the browser treats them as distinct origins. When sending a JSON POST request, the browser blocks it unless the server responds with an explicit Access-Control-Allow-Origin header.
